💬Common questions

What is the country code for India?

India's country code is +91. Dial it after your international exit code (or after + on a mobile), followed by the 10-digit Indian phone number.

How do I call India from the United States?

From a US mobile: dial +91 then the 10-digit number. From a landline: dial 011 91 then the number. Example: 011 91 98765 43210.

Why does the Indian number I was given start with 0?

The leading 0 is India's domestic trunk prefix — it's only used when dialing within India. Drop it when calling from abroad: 098765 43210 becomes +91 98765 43210.

Can I keep my Indian number when switching carriers?

Yes — India has nationwide Mobile Number Portability. Text PORT followed by your number to 1900, take the code you receive to the new carrier, and the switch typically completes in 3–5 working days. You keep your number even when moving between states.

Is +91 a WhatsApp number?

+91 simply means the number is Indian. Any Indian mobile (10 digits starting 6–9) can be on WhatsApp — save it as +91 followed by the full number, with no spaces and no leading zero.

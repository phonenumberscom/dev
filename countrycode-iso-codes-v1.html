IN

Alpha-2 — two letters

The most widely used format: internet domains (.in), shipping, currency prefixes and software locales. Defined in ISO 3166-1 alpha-2.

IND

Alpha-3 — three letters

Closer to the country name, so easier to recognize. Used on passports, in banking (IBAN, SWIFT), at the UN and in international sport.

356

Numeric — three digits

Script-independent, so it works in any language or alphabet. Used by the UN Statistics Division and in EMV chip payment systems.

💬Common questions

What's the difference between Alpha-2 and Alpha-3 codes?

Both identify the same country. Alpha-2 (two letters, like DE) is the general-purpose standard used for internet domains and software. Alpha-3 (three letters, like DEU) resembles the country name more closely and is preferred on passports and in finance. Germany is DE, DEU and 276 — all three are ISO 3166-1 codes.

Is a country's ISO code the same as its phone code?

No — they're different systems. ISO codes are letters and digits assigned by the ISO standards body; calling codes (like +49) are assigned by the ITU for telephone routing. This table cross-references both, which is why India shows IN / IND / 356 and +91.

Why isn't Kosovo in the list?

Kosovo doesn't yet have an official ISO 3166 code. The user-assigned code XK is widely used in practice (by the EU, SWIFT and many databases), and Kosovo does have its own calling code, +383.

Which country names have changed recently?

The standard now uses Czechia (Czech Republic), Eswatini (formerly Swaziland), Cabo Verde (Cape Verde), North Macedonia (formerly Macedonia) and Timor-Leste (East Timor). We show the name people actually search for, with the official ISO name alongside.

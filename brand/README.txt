PhoneNumbers.com Final Brand Assets
===================================

FINAL APPROVED SYSTEM
---------------------
This package is the final approved export of the version 1.2 identity system.

FINAL LOGO DECISIONS
--------------------
- Main wordmark: Plus Jakarta Sans SemiBold 600.
- ".com": Plus Jakarta Sans Regular 400 at 72.5% of the main wordmark size.
- Primary pound-sign cut: Fine Cut, 9.6% stroke.
- Small-size pound-sign cut: Current Cut, 11.5% stroke.
- Brand Purple: #5B3FE8
- Ink: #0A0F1E

The primary and small-size marks are optical sizes of the same design. The
slightly stronger small cut prevents the pound sign from becoming weak or
uneven when rasterized at favicon dimensions.

FOLDERS
-------
vector/
  Outlined, resolution-independent SVG files.
  - primary: purple mark plus ink wordmark
  - ink: approved single-color treatment
  - white: transparent reversed treatment for dark backgrounds
  - mark-small: 11.5% cut for favicons and small UI icons

pdf/
  Vector print PDFs with outlined wordmarks and no raster image objects.
  Reversed PDFs include the approved Ink background.

png/
  Transparent lockups and standalone primary marks at 256, 512, 1024,
  and 2048 pixels wide. Standalone marks are square.

favicon/
  Multi-resolution ICO containing 16, 32, and 48 pixel sizes.
  PNG versions are included at 16, 26, 32, 40, 48, 180, 192, and 512 pixels.
  These files use the 11.5% small-size cut.

preview/
  Reference sheet showing primary, page-tint, reversed, and ink treatments.

CONSTRUCTION
------------
- Mark corner radius: 27.5% of mark width.
- Primary mark cut: 9.6% stroke with round terminals.
- Small-size mark cut: 11.5% stroke with round terminals.
- Pound-sign vertical strokes use the traditional telephone-key slant.
- Clear space: at least 0.5 times the key height on all sides.
- Full lockup minimum: 22 pixel mark height.
- Below 22 pixels, use the mark alone.
- Wordmark letter spacing: -0.02em.
- Mark-to-wordmark gap: 38% of mark width.

USAGE
-----
- Use primary on white or Page Tint (#F7F8FA).
- Use white on dark backgrounds.
- Use ink for single-color reproduction.
- Use the small-size mark for favicon and compact UI placements.
- Do not recolor, stretch, rotate, outline, shadow, or apply gradients.
- Do not replace the pound sign with a text character.
- Prefer SVG for web and PDF/SVG for print.
